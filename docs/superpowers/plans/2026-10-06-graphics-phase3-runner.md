# Graphics Overhaul Phase 3 — Runner — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the chibi stacked-primitive runner with a taller, heroic, about-7-heads figure made of sculpted shells, and give it a keyframed run cycle, landing squash, takeoff stretch and a spinning roll tuck.

**Architecture:**
- Pure pose math lives in `Sources/WorldRunnerPose.swift` as `enum RunnerPose`. It holds the keyframe tables, a periodic Catmull-Rom sampler, blends, springs, squash and spin. It uses Foundation only.
- The rig lives in `Sources/WorldRunner.swift` as `extension CoastalWorld`. It holds the lathe and shell builders, the new `makePlayer()` and `poseRunner(...)`.
- Each rig bone carries one merged multi-material geometry, so about 150 geometry nodes become 46 (14 visible).
- `update(simulation:...)` keeps computing the blends and ages, and calls `poseRunner` instead of the inline sine code.
- `player.position` keeps its contract. Sway, bob, squash and the tuck happen on `body`.

**Tech Stack:** Swift 5.9, SceneKit, simd. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-06-graphics-overhaul-design.md` (Phase 3 section, Constraints, Verification). Runner map: `work/phase3-runner-map.md`.

## Reference facts (verified by probe at `be57cb0`, `work/phase3/Probe.swift`)

- Today's runner has 169 nodes and 151 geometry nodes: 119 visible, plus 32 hidden (19 jet ski, 4 board, 6 jetpack, 3 aura). It uses 71 distinct materials.
- Bind-pose y-range is −0.045 to 2.494 m. The hip pivot is at 0.77 (0.31 of height), and the head is about 1/4 of height.
- Old roll at 14 frames has a y-range of 0.04 to 0.92 m (box corners). The overhead obstacles set the tuck's ceiling:
  - The harbor `makeArch` shutter underside is at 0.73 m, which the old roll already clips for one or two frames.
  - The off-world arch underside is about 1.69 m.
  - The laser beam underside is 1.335 m.
- Rotation signs follow the SceneKit right-hand rule, and the runner faces −z.
  - `eulerAngles.x > 0` on a limb hanging down swings it forward (−z).
  - A negative shin bends the knee, and a positive foot lifts the toe.
  - The old rig set forearms negative, which bent the elbows backward. The new tables use a positive forearm for a forward elbow bend.
  - `body.eulerAngles.x < 0` leans the torso forward.
- `SCNNode.pivot` does not rotate a node about the pivot point. The probe `work/phase3/piv.swift` shows the node rotates and scales about its own origin, then shifts by −pivot in parent space. The tuck therefore keeps `pivot` at identity and compensates its spin centre in `position` (Task 4).
- `SCNNode.flattenedClone()` geometry reports an empty `materials` array until it is rendered (phase-2 ruling). The shells are therefore merged by hand into one `SCNGeometry` with one element per material. That keeps `clothing` tinting and MaterialTests deterministic.
- Swift extensions cannot add stored properties. New rig state (`pack`, springs, spin) is declared in the `CoastalWorld` class body. Members the extension reads change from `private` to internal.
- `updateGhost` clones `player` once (sharing geometry and materials) and then only swings the four named limbs. Everything else keeps its clone-time pose.
- Harness facts:
  - The throwaway close-up camera sat at a fixed offset 4.9 m from the player origin, aimed 1.25 m up. The old roll pitches the body 90° toward that camera, so `work/shots/runner-before/roll.png` shows a cropped torso; with the taller rig the same camera also crops the helmet crest. The promoted harness fits the camera to the runner's visible world box instead. Verified on `be57cb0` and on a scratch build of this plan's rig: both roll shots frame the whole runner.
  - The menu scene parks a bus in the lane right of the runner, so the menu-pose close-up shoots from the front-left.
  - The live sim starts running on `start(...)`.
  - `RunnerSimulation()` is in `.menu`.
  - `act(.board)` with `boards ≥ 1` starts surfing.
  - The jetpack and aura can only be forced for a placement check by unhiding their nodes before a snapshot.

```swift
@main struct RunnerTests {
    static func field<T>(_ world: CoastalWorld, _ label: String) -> T {
        Mirror(reflecting: world).children.first { $0.label == label }!.value as! T

    static func near(_ a: RunnerPose.Limbs, _ b: RunnerPose.Limbs) -> Bool {
        [a.thigh - b.thigh, a.shin - b.shin, a.foot - b.foot, a.arm - b.arm, a.forearm - b.forearm].allSatisfy { abs($0) < 1e-9 }

    /// Exact vertices of visible geometry under `root`, in `space` coordinates, skipping the `except` subtree.
    /// Parametric primitives (SCNBox, SCNCapsule…) fall back to their bounding-box corners.
    static func points(under root: SCNNode, in space: SCNNode, except: SCNNode? = nil) -> [SIMD3<Double>] {
        var out: [SIMD3<Double>] = []
        func visit(_ node: SCNNode) {
            guard !node.isHidden, node !== except else { return }
            if let g = node.geometry {
                var local: [SCNVector3] = []
                if type(of: g) == SCNGeometry.self, let s = g.sources(for: .vertex).first {
                    s.data.withUnsafeBytes { raw in
                        for i in 0..<s.vectorCount {
                            let base = s.dataOffset + i * s.dataStride
                            func c(_ k: Int) -> Double {
                                s.bytesPerComponent == 4 ? Double(raw.loadUnaligned(fromByteOffset: base + 4 * k, as: Float.self))
                                                         : raw.loadUnaligned(fromByteOffset: base + 8 * k, as: Double.self)
                            }
                            local.append(SCNVector3(c(0), c(1), c(2)))
                        }
                    }
                } else {
                    let (a, b) = g.boundingBox
                    for k in 0..<8 { local.append(SCNVector3(k & 1 == 0 ? a.x : b.x, k & 2 == 0 ? a.y : b.y, k & 4 == 0 ? a.z : b.z)) }
                }
                for p in local {
                    let w = space.convertPosition(p, from: node)
                    out.append(SIMD3(Double(w.x), Double(w.y), Double(w.z)))
                }
            }
            node.childNodes.forEach(visit)
        }

        return out
```

```swift
import Foundation

/// Pure run-cycle math for the runner rig: keyframed joint curves sampled by gait phase, blends and springs.
/// Angles are radians about x. A positive thigh or arm swings forward (the runner faces −z), a negative shin
/// bends the knee, a positive forearm bends the elbow, and a positive foot lifts the toe.
enum RunnerPose {
    struct Limbs: Equatable {
        var thigh = 0.0, shin = 0.0, foot = 0.0, arm = 0.0, forearm = 0.0
    }

    /// Left-side keys, eight per stride, spaced evenly over one gait period (2π): left contact, down, passing, up,
    /// then left toe-off, recoil, passing and reach. The right side samples the same curves at phase + π.
    static let thighKeys: [Double] = [0.45, 0.25, -0.05, -0.40, -0.55, -0.20, 0.45, 0.70]
    static let shinKeys: [Double] = [-0.15, -0.45, -0.35, -0.15, -0.60, -1.70, -1.50, -0.55]
    static let footKeys: [Double] = [0.20, 0.00, -0.05, -0.45, -0.60, -0.30, 0.10, 0.25]
    static let armKeys: [Double] = [-0.50, -0.35, 0.00, 0.40, 0.55, 0.35, -0.10, -0.45]
    static let forearmKeys: [Double] = [0.70, 0.80, 1.00, 1.30, 1.40, 1.25, 0.95, 0.75]
    /// Per stride: hip sway toward the stance foot (metres on body x; the left foot is at −x), torso twist
    /// (positive while the left leg leads, so the right shoulder counter-rotates forward) and side tilt over the stance foot.
    static let swayKeys: [Double] = [-0.020, -0.035, -0.030, -0.010, 0.020, 0.035, 0.030, 0.010]
    static let yawKeys: [Double] = [0.10, 0.07, 0.00, -0.07, -0.10, -0.07, 0.00, 0.07]
    static let rollKeys: [Double] = [0.02, 0.04, 0.03, 0.00, -0.02, -0.04, -0.03, 0.00]
    /// Per step (contact, down, passing, up), repeated for each foot (period π): body lift in metres and forward lean.
    static let bobKeys: [Double] = [-0.02, -0.07, 0.00, 0.05]
    static let leanKeys: [Double] = [0.06, 0.09, 0.07, 0.05]
    /// Standing pose the run cycle scales from: knees and elbows slightly soft.
    static let rest = Limbs(thigh: 0, shin: -0.10, foot: 0, arm: 0, forearm: 0.35)

    /// Periodic Catmull-Rom through `keys` spaced evenly over 2π: it passes through every key and is C1 (no velocity jump).
    static func sample(_ keys: [Double], phase: Double) -> Double {
        let n = keys.count
        var t = phase / (2 * .pi) * Double(n)
        t -= (t / Double(n)).rounded(.down) * Double(n)
        let i = Int(t), f = t - Double(i)
        func k(_ j: Int) -> Double { keys[((j % n) + n) % n] }
        let p0 = k(i - 1), p1 = k(i), p2 = k(i + 1), p3 = k(i + 2)
        return 0.5 * (2 * p1 + (p2 - p0) * f + (2 * p0 - 5 * p1 + 4 * p2 - p3) * f * f + (3 * p1 - p0 - 3 * p2 + p3) * f * f * f)
    }

    /// Both sides at gait `phase` (radians): the right side runs half a stride behind the left.
    static func limbs(phase: Double) -> (left: Limbs, right: Limbs) {
        func side(_ p: Double) -> Limbs {
            Limbs(thigh: sample(thighKeys, phase: p), shin: sample(shinKeys, phase: p), foot: sample(footKeys, phase: p),
                  arm: sample(armKeys, phase: p), forearm: sample(forearmKeys, phase: p))
        }
        return (side(phase), side(phase + .pi))
    }

    /// Body channels at gait `phase`. Bob and lean repeat every step, so they sample at twice the phase.
    static func torso(phase: Double) -> (sway: Double, bob: Double, lean: Double, yaw: Double, roll: Double) {
        (sample(swayKeys, phase: phase), sample(bobKeys, phase: phase * 2), sample(leanKeys, phase: phase * 2),
         sample(yawKeys, phase: phase), sample(rollKeys, phase: phase))
    }

    static func mix(_ a: Limbs, _ b: Limbs, _ t: Double) -> Limbs {
        func m(_ x: Double, _ y: Double) -> Double { x + (y - x) * t }
        return Limbs(thigh: m(a.thigh, b.thigh), shin: m(a.shin, b.shin), foot: m(a.foot, b.foot), arm: m(a.arm, b.arm), forearm: m(a.forearm, b.forearm))
    }

    /// Damped spring for follow-through (semi-implicit Euler; stable for dt ≤ 0.05 at these stiffnesses).
    struct Spring: Equatable { var value = 0.0, velocity = 0.0 }

    static func step(_ s: Spring, target: Double, dt: Double, stiffness: Double, damping: Double) -> Spring {
        var s = s
        s.velocity += ((target - s.value) * stiffness - s.velocity * damping) * dt
        s.value += s.velocity * dt
        return s
    }
```

```swift
/// (one element per material), so the rig is 14 visible geometry nodes instead of ~120 primitives.
extension CoastalWorld {
    typealias Shell = (rings: [(Double, Double, Double)], at: SIMD3<Double>, material: SCNMaterial)

    func shell(_ rings: [(Double, Double, Double)], _ material: SCNMaterial, at offset: SIMD3<Double> = .zero) -> Shell {
        (rings, offset, material)
    }

    /// Lathe surface around the y axis: rings are (y, radiusX, radiusZ), ascending in y; 24 segments, analytic normals,
    /// optional flat end caps. Without caps this is exactly the old `sculptedMesh` surface.
    func latheMesh(rings: [(Double, Double, Double)], caps: Bool, at offset: SIMD3<Double> = .zero)
        -> (vertices: [SCNVector3], normals: [SCNVector3], uv: [CGPoint], indices: [Int32]) {
        let segments = 24
        var vertices: [SCNVector3] = [], normals: [SCNVector3] = [], uv: [CGPoint] = [], indices: [Int32] = []
        func add(_ x: Double, _ y: Double, _ z: Double, _ n: SIMD3<Float>, _ u: Double, _ v: Double) {
            vertices.append(vector(x + offset.x, y + offset.y, z + offset.z))
            normals.append(vector(Double(n.x), Double(n.y), Double(n.z)))
            uv.append(CGPoint(x: u, y: v))
        }
        for (row, section) in rings.enumerated() {
            let before = rings[max(0, row - 1)], after = rings[min(rings.count - 1, row + 1)]
            let dy = max(0.01, after.0 - before.0)
            for column in 0...segments {
                let angle = Double(column) / Double(segments) * .pi * 2
                let c = cos(angle), s = sin(angle)
                let n = simd_normalize(SIMD3<Float>(Float(c / section.1), Float(-((after.1 - before.1) * c * c / section.1 + (after.2 - before.2) * s * s / section.2) / dy), Float(s / section.2)))
                add(section.1 * c, section.0, section.2 * s, n, Double(column) / Double(segments), Double(row) / Double(max(1, rings.count - 1)))
                if row < rings.count - 1 && column < segments {
                    let a = Int32(row * (segments + 1) + column), b = a + Int32(segments + 1)
                    indices += [a, b, a + 1, a + 1, b, b + 1]
                }
            }
        }
        if caps {
            for (section, down) in [(rings[0], true), (rings[rings.count - 1], false)] {
                let n = SIMD3<Float>(0, down ? -1 : 1, 0)
                let centre = Int32(vertices.count)
                add(0, section.0, 0, n, 0.5, down ? 0 : 1)
                for column in 0...segments {
                    let angle = Double(column) / Double(segments) * .pi * 2
                    add(section.1 * cos(angle), section.0, section.2 * sin(angle), n, 0.5 + cos(angle) * 0.5, down ? 0 : 1)
                }
                for column in 0..<segments {
                    let a = centre + 1 + Int32(column)
                    indices += down ? [centre, a, a + 1] : [centre, a + 1, a]
                }
            }
        }
        return (vertices, normals, uv, indices)
    }

        for part in shells {
            let mesh = latheMesh(rings: part.rings, caps: true, at: part.at)
            let base = Int32(vertices.count)
            vertices += mesh.vertices; normals += mesh.normals; uv += mesh.uv
            let shifted = mesh.indices.map { $0 + base }
            if let i = groups.firstIndex(where: { $0.material === part.material }) { groups[i].indices += shifted }
            else { groups.append((part.material, shifted)) }
        }
        let geometry = SCNGeometry(sources: [SCNGeometrySource(vertices: vertices), SCNGeometrySource(normals: normals), SCNGeometrySource(textureCoordinates: uv)],
                                   elements: groups.map { SCNGeometryElement(indices: $0.indices, primitiveType: .triangles) })
        geometry.materials = groups.map(\.material)
        return geometry
```

```swift
                    takeoffAge: Double, speed: Double, height: Double, time: Double, dt: Double) {

        let air = airborneBlend, tuck = rollBlend

        let crouch = (landingAge < 0.32 ? sin(landingAge / 0.32 * .pi) : 0) + (takeoffAge < 0.10 ? (1 - takeoffAge / 0.10) * 0.45 : 0)
        for i in 0..<2 {
            let side = i == 0 ? -1.0 : 1.0
            var j = RunnerPose.mix(RunnerPose.rest, i == 0 ? gaitPose.left : gaitPose.right, amount)
            j = RunnerPose.mix(j, i == 0 ? RunnerPose.airLeft : RunnerPose.airRight, air)
            j = RunnerPose.mix(j, RunnerPose.tuck, tuck)
            if waterMode { j = RunnerPose.ride }
            j.thigh += crouch * 0.5; j.shin -= crouch * 1.0
            let leg = i == 0 ? leftLeg : rightLeg, arm = i == 0 ? leftArm : rightArm
            leg.eulerAngles = vector(j.thigh, 0, side * (waterMode ? RunnerPose.rideSplay : surfing ? 0.12 : 0.02))
            shins[i].eulerAngles.x = scalar(j.shin)
            feet[i].eulerAngles.x = scalar(j.foot)
```

```swift
    /// Volume-preserving scale for vertical factor `y`: x and z take 1/√y.
    static func volumeScale(_ y: Double) -> (x: Double, y: Double, z: Double) {
        let w = 1 / y.squareRoot()
        return (w, y, w)
    }

    /// Roll tuck ball: spin centre in body space (1.5–1.9), its height above the deck (0.55–0.70) and
    /// the ball's scale (0.65–0.85; the 2.5 m figure must fit under the 1.30 m roll ceiling).
    static let tuckCentre = 1.75, tuckRadius = 0.65, tuckScale = 0.74
    /// One forward revolution per 0.8 s roll.
    static let spinRate = 2 * Double.pi / 0.8

    /// Roll spin in 0..<2π. While rolling it keeps turning; afterwards it finishes the turn and rests at 0 (upright).
    static func advanceSpin(_ angle: Double, rolling: Bool, dt: Double) -> Double {
        guard rolling || angle > 0 else { return 0 }
        let next = angle + dt * spinRate
        if next < 2 * .pi { return next }
        return rolling ? next - 2 * .pi : 0
    }
```
