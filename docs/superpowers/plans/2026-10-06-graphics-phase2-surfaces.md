# Graphics Overhaul Phase 2 — Surfaces and Geometry — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace flat single-color plastic and placeholder primitives with detailed surfaces, faceted rocks, crystal clusters, eroded terrain, curved alien trees, varied harbor roofs and higher-resolution deck and road textures.

**Architecture:** A model-space triplanar surface-detail shader is attached to every lit, non-emissive material created by `CoastalWorld.material()`. It samples one generated 512² tileable detail texture. New geometry builders live in `Sources/WorldProps.swift` as pure functions or node builders. The existing `makeRock`, `makeCrystal`, `makeTerrain`, `makeAlienTree` and `makeHouse` call those builders, so every call site and all scenery placement stay unchanged. Deck and asphalt textures are redrawn at higher resolution in place.

**Tech Stack:** Swift 5.9, SceneKit (Metal shader modifiers), CoreGraphics. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-06-graphics-overhaul-design.md` (Phase 2 section, Constraints)

## Global Constraints

- iOS 16+ / macOS 13+; one shared `Sources/` tree builds both targets.
- No changes to `RunnerSimulation`, collisions, hitboxes, lane spacing (2.6 m) or entity placement. Tall scenery stays outside ±5 m of the track centerline.
- No downloaded art; every asset is generated by code in this repo.
- Static geometry stays merged via `flattenPreservingHierarchy`; entity pools and node counts stay within `WorldCacheAudit` bounds (≤2 destinations, ≤96 pooled).
- No color-grading LUT (dropped in phase 1; `applyLook` keeps `colorGrading.contents = nil`).
- Render acceptance after every task (`Scripts/render.sh <label>`):
  - mean 0.18–0.45 and clipped ≤ 1.5% for every shot;
  - crushed ≤ 3% for every shot except orbit, which may be ≤ 6%;
  - ms within +25% of the phase-1 final values: harbor 286, orbit 117, mars 131, verdant 254, cryo 141, forge 149, jetski 279.
- After every task: `Scripts/test.sh` passes, and both the Mac and iOS builds succeed.
- Environment: `swiftc`, `xcodebuild`, `xcodegen`, `Scripts/*.sh` must run outside the Claude sandbox. Outputs go to `work/` (gitignored), never `$TMPDIR`. `precondition` messages do not print in `-O` builds; rebuild without `-O` to read a failure.

## Reference facts (verified by probe, 2026-10-06)

- Metal surface shader modifiers accept a custom texture declared as `#pragma arguments` / `texture2d<float> detailMap;`, bound with `material.setValue(SCNMaterialProperty(contents:), forKey: "detailMap")`.
- `scn_node.inverseModelViewTransform * float4(_surface.position, 1)` gives model-space positions. A node and camera translated together render byte-identically, so the pattern does not swim on scrolling sections or pooled props.
- `SCNMaterial.copy()` keeps `shaderModifiers` and custom KVC values (`detailMap`, numbers). `SCNGeometry.copy()` shares vertex data; assigning `firstMaterial` on the copy leaves the original untouched.
- `_surface.position` and `_surface.normal` are view space in the surface entry point. `_surface.roughness` is writable (the ocean modifier already writes it).
- Materials that later assign their own `shaderModifiers` (ocean, planet, reactor core, aurora, portal field) replace the detail modifier; that is intended.

```swift
import SceneKit

/// Model-space surface detail shared by every lit, non-emissive material. Model space keeps the
/// pattern fixed to scrolling sections and pooled props, so it never swims as the world moves.
extension CoastalWorld {
    static let surfaceDetailModifier = """
    #pragma arguments
    texture2d<float> detailMap;
    float detailScale;
    float detailStrength;
    #pragma body
    constexpr sampler detailSampler(filter::linear, mip_filter::linear, address::repeat);
    float3 local = (scn_node.inverseModelViewTransform * float4(_surface.position, 1.0)).xyz;
    float3 w = abs(normalize((scn_node.inverseModelViewTransform * float4(_surface.normal, 0.0)).xyz));
    w = pow(w, float3(4.0)); w /= max(0.0001, w.x + w.y + w.z);
    float3 p = local * detailScale;
    float4 broad = detailMap.sample(detailSampler, p.yz) * w.x + detailMap.sample(detailSampler, p.xz) * w.y + detailMap.sample(detailSampler, p.xy) * w.z;
    float3 q = p * 4.7 + 0.31;
    float4 fine = detailMap.sample(detailSampler, q.yz) * w.x + detailMap.sample(detailSampler, q.xz) * w.y + detailMap.sample(detailSampler, q.xy) * w.z;
    float breakup = (broad.r - 0.5) * 2.0;
    float grain = (fine.g - 0.5) * 2.0;
    _surface.diffuse.rgb *= 1.0 + detailStrength * (0.22 * breakup + 0.10 * grain - 0.35 * broad.b);
    _surface.roughness = clamp(_surface.roughness + detailStrength * (0.18 * breakup + 0.12 * fine.g - 0.06), 0.04, 1.0);
    """

    /// 512² tileable data texture (linear, not color): R broad fbm, G fine fbm, B cavities and specks.
    func detailTexture() -> CGImage? {
        if let cached = textureCache["surface-detail"] { return cached }
        let size = 512
        func lattice(_ x: Int, _ y: Int, _ period: Int, _ seed: UInt64) -> Double {
            // Split into steps: one long mixed &*/^ expression times out the type checker.
            var h = UInt64(x % period) &* 0x9E37_79B9_7F4A_7C15
            h ^= UInt64(y % period) &* 0xC2B2_AE3D_27D4_EB4F
            h ^= seed
            h ^= h >> 31; h = h &* 0x94D0_49BB_1331_11EB; h ^= h >> 29
            return Double(h & 0xFFFF) / 65535
        }
        func noise(_ u: Double, _ v: Double, period: Int, seed: UInt64) -> Double {
            let x = u * Double(period), y = v * Double(period)
            let xi = Int(x), yi = Int(y), fx = x - Double(xi), fy = y - Double(yi)
            let sx = fx * fx * (3 - 2 * fx), sy = fy * fy * (3 - 2 * fy)
            let a = lattice(xi, yi, period, seed), b = lattice(xi + 1, yi, period, seed)
            let c = lattice(xi, yi + 1, period, seed), d = lattice(xi + 1, yi + 1, period, seed)
            let top = a + (b - a) * sx, bottom = c + (d - c) * sx
            return top + (bottom - top) * sy
        }
        func fbm(_ u: Double, _ v: Double, base: Int, seed: UInt64) -> Double {
            var sum = 0.0, amplitude = 0.5, norm = 0.0, period = base
            for octave in 0..<4 { sum += noise(u, v, period: period, seed: seed &+ UInt64(octave)) * amplitude; norm += amplitude; amplitude *= 0.5; period *= 2 }
            return sum / norm
        }
        var pixels = [UInt8](repeating: 255, count: size * size * 4)
        for y in 0..<size { for x in 0..<size {
            let u = Double(x) / Double(size), v = Double(y) / Double(size)
            let broad = fbm(u, v, base: 4, seed: 11), fine = fbm(u, v, base: 32, seed: 23)
            let speck = noise(u, v, period: 128, seed: 37)
            let cavity = min(1, max(0, (speck - 0.78) / 0.22) * 0.8 + max(0, (0.30 - broad) / 0.30) * 0.4)
            let i = (y * size + x) * 4
            pixels[i] = UInt8(broad * 255); pixels[i + 1] = UInt8(fine * 255); pixels[i + 2] = UInt8(cavity * 255)
        } }
        let result = Self.rgbaImage(pixels, width: size, height: size)
        textureCache["surface-detail"] = result
        return result
    }

    func applySurfaceDetail(to material: SCNMaterial, scale: Double = 0.45, strength: Double = 1) {
        material.shaderModifiers = [.surface: Self.surfaceDetailModifier]
        let map = SCNMaterialProperty(contents: detailTexture() as Any)
        map.wrapS = .repeat; map.wrapT = .repeat
        map.minificationFilter = .linear; map.magnificationFilter = .linear; map.mipFilter = .linear
        material.setValue(map, forKey: "detailMap")
        material.setValue(NSNumber(value: scale), forKey: "detailScale")
        material.setValue(NSNumber(value: strength), forKey: "detailStrength")
    }

    /// Linear-space RGBA so data textures are not gamma-decoded when sampled.
    static func rgbaImage(_ pixels: [UInt8], width: Int, height: Int) -> CGImage? {
        guard let provider = CGDataProvider(data: Data(pixels) as CFData),
              let space = CGColorSpace(name: CGColorSpace.linearSRGB) else { return nil }
        return CGImage(width: width, height: height, bitsPerComponent: 8, bitsPerPixel: 32, bytesPerRow: width * 4,
                       space: space, bitmapInfo: CGBitmapInfo(rawValue: CGImageAlphaInfo.noneSkipLast.rawValue),
                       provider: provider, decode: nil, shouldInterpolate: true, intent: .defaultIntent)
    }
}
```

```swift
import SceneKit

/// Shared prop geometry. Builders return detached nodes; the `make…` call sites place and merge them.
extension CoastalWorld {
    /// Smooth 3D value noise in 0...1, deterministic on every platform.
    static func valueNoise(_ x: Double, _ y: Double, _ z: Double, seed: Int = 0) -> Double {
        func hash(_ i: Int, _ j: Int, _ k: Int) -> Double {
            // Split into steps: one long mixed &*/^ expression times out the type checker.
            var mixed = i &* 73_856_093
            mixed ^= j &* 19_349_663
            mixed ^= k &* 83_492_791
            mixed ^= seed &* 2_654_435_761
            var h = UInt64(bitPattern: Int64(mixed))
            h ^= h >> 33; h = h &* 0xFF51_AFD7_ED55_8CCD; h ^= h >> 33
            return Double(h & 0xFFFF) / 65535
        }
        func lerp(_ a: Double, _ b: Double, _ t: Double) -> Double { a + (b - a) * t }
        let xi = Int(floor(x)), yi = Int(floor(y)), zi = Int(floor(z))
        let fx = x - floor(x), fy = y - floor(y), fz = z - floor(z)
        let u = fx * fx * (3 - 2 * fx), v = fy * fy * (3 - 2 * fy), w = fz * fz * (3 - 2 * fz)
        let x00 = lerp(hash(xi, yi, zi), hash(xi + 1, yi, zi), u)
        let x10 = lerp(hash(xi, yi + 1, zi), hash(xi + 1, yi + 1, zi), u)
        let x01 = lerp(hash(xi, yi, zi + 1), hash(xi + 1, yi, zi + 1), u)
        let x11 = lerp(hash(xi, yi + 1, zi + 1), hash(xi + 1, yi + 1, zi + 1), u)
        return lerp(lerp(x00, x10, v), lerp(x01, x11, v), w)
    }

    /// Flat-shaded triangles: three unique vertices per face, each carrying the face normal.
    /// Triangles must be counter-clockwise seen from outside.
    static func facetedGeometry(_ triangles: [(SIMD3<Double>, SIMD3<Double>, SIMD3<Double>)],
                                uv: (SIMD3<Double>) -> CGPoint) -> SCNGeometry {
        var vertices: [SCNVector3] = [], normals: [SCNVector3] = [], coordinates: [CGPoint] = []
        for (a, b, c) in triangles {
            let n = simd_normalize(simd_cross(b - a, c - a))
            for p in [a, b, c] {
                vertices.append(SCNVector3(CoastScalar(p.x), CoastScalar(p.y), CoastScalar(p.z)))
                normals.append(SCNVector3(CoastScalar(n.x), CoastScalar(n.y), CoastScalar(n.z)))
                coordinates.append(uv(p))
            }
        }
        let element = SCNGeometryElement(indices: Array(0..<Int32(vertices.count)), primitiveType: .triangles)
        return SCNGeometry(sources: [SCNGeometrySource(vertices: vertices), SCNGeometrySource(normals: normals),
                                     SCNGeometrySource(textureCoordinates: coordinates)], elements: [element])
    }

    /// Faceted boulder: icosahedron subdivided twice, noise-displaced, with a settled base. Unit radius.
    func rockGeometry(variant: Int) -> SCNGeometry {
        let slot = ((variant % 4) + 4) % 4
        let key = "rock-\(slot)"
        if let cached = geometryCache[key] { return cached }
        let t = (1 + 5.0.squareRoot()) / 2
        var points: [SIMD3<Double>] = [
            SIMD3(-1, t, 0), SIMD3(1, t, 0), SIMD3(-1, -t, 0), SIMD3(1, -t, 0),
            SIMD3(0, -1, t), SIMD3(0, 1, t), SIMD3(0, -1, -t), SIMD3(0, 1, -t),
            SIMD3(t, 0, -1), SIMD3(t, 0, 1), SIMD3(-t, 0, -1), SIMD3(-t, 0, 1),
        ].map { simd_normalize($0) }
        var faces: [(Int, Int, Int)] = [
            (0, 11, 5), (0, 5, 1), (0, 1, 7), (0, 7, 10), (0, 10, 11), (1, 5, 9), (5, 11, 4), (11, 10, 2), (10, 7, 6), (7, 1, 8),
            (3, 9, 4), (3, 4, 2), (3, 2, 6), (3, 6, 8), (3, 8, 9), (4, 9, 5), (2, 4, 11), (6, 2, 10), (8, 6, 7), (9, 8, 1),
        ]
        for _ in 0..<2 {
            var midpoints: [Int: Int] = [:]
            func midpoint(_ a: Int, _ b: Int) -> Int {
                let key = min(a, b) * 4096 + max(a, b)
                if let found = midpoints[key] { return found }
                points.append(simd_normalize((points[a] + points[b]) / 2))
                midpoints[key] = points.count - 1
                return points.count - 1
            }
            var next: [(Int, Int, Int)] = []
            for (a, b, c) in faces {
                let ab = midpoint(a, b), bc = midpoint(b, c), ca = midpoint(c, a)
                next += [(a, ab, ca), (b, bc, ab), (c, ca, bc), (ab, bc, ca)]
            }
            faces = next
        }
        let seed = Double(slot) * 17.3
        let displaced = points.map { p -> SIMD3<Double> in
            let broad = Self.valueNoise(p.x * 1.6 + seed, p.y * 1.6, p.z * 1.6) - 0.5
            let fine = Self.valueNoise(p.x * 4.1, p.y * 4.1 + seed, p.z * 4.1) - 0.5
            var q = p * (1 + broad * 0.55 + fine * 0.16)
            if q.y < -0.35 { q.y = -0.35 + (q.y + 0.35) * 0.2 }   // settle onto the ground
            return q
        }
        let triangles = faces.map { f -> (SIMD3<Double>, SIMD3<Double>, SIMD3<Double>) in
            let a = displaced[f.0], b = displaced[f.1], c = displaced[f.2]
            // Strong displacement can fold a face inward; keep every face outward-wound.
            return simd_dot(simd_cross(b - a, c - a), a + b + c) < 0 ? (a, c, b) : (a, b, c)
        }
        let geometry = Self.facetedGeometry(triangles) { p in
            CGPoint(x: atan2(p.x, p.z) / (2 * .pi) + 0.5, y: p.y * 0.5 + 0.5)
        }
        geometryCache[key] = geometry
        return geometry
    }

    /// A rock with its own material; same footprint as the old squashed sphere (1.4 × 0.8 × 1 radii).
    func rockNode(size: Double, material: SCNMaterial, variant: Int) -> SCNNode {
        let geometry = rockGeometry(variant: variant).copy() as! SCNGeometry
        geometry.firstMaterial = material
        let node = SCNNode(geometry: geometry)
        node.scale = SCNVector3(CoastScalar(size * 1.4), CoastScalar(size * 0.8), CoastScalar(size))
        return node
    }

    /// Hexagonal crystal cluster `height` metres tall: one main shard and three tilted satellites, base at y = 0.
    func crystalCluster(height: Double, material: SCNMaterial) -> SCNNode {
        let cluster = SCNNode()
        let shards: [(x: Double, z: Double, scale: Double, tilt: Double)] = [
            (0, 0, 1, 0), (0.16, 0.05, 0.62, 0.32), (-0.13, 0.09, 0.48, -0.38), (0.03, -0.15, 0.4, 0.25),
```

```swift
    /// Valley-wall heightfield for one 26 m section. Rows run outward from the track edge (row 0 at |x| = 7.5),
    /// columns along local z. Noise is keyed by world distance, so neighbouring sections share their edge vertices.
    static func terrainVertices(side: Double, index: Int, icy: Bool, columns: Int = 41, rows: Int = 11) -> [SIMD3<Double>] {
        var result: [SIMD3<Double>] = []
        result.reserveCapacity(columns * rows)
        let seed = side > 0 ? 7.0 : 0.0
        for row in 0..<rows { for column in 0..<columns {
            let z = -13 + Double(column) * 26 / Double(columns - 1)
            let distance = Double(index) * 26 - z
            let fraction = Double(row) / Double(rows - 1)
            let broad = valueNoise(distance * 0.11, fraction * 2.3, seed) - 0.5
            let detail = valueNoise(distance * 0.43, fraction * 6.1, seed + 3) - 0.5

            let x = side * (7.5 + fraction * 21.6 + broad * 2.4 * fraction)
            result.append(SIMD3(x, y, z))
        } }
        return result
    }
```
